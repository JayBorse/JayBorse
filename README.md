Engineering Principles

Build locally when possible.
Developer tools should minimize unnecessary data leaving the developer’s machine.

Prefer small, composable tools.
A focused CLI or MCP server is often more useful than another large platform.

Measure before optimizing.
Performance, binary size, latency, and infrastructure cost should be measurable engineering decisions.

Make complex systems easy to use.
The best developer tooling hides complexity without hiding control.

Ship real software.
I value production experience, distribution, testing, and maintenance as much as prototypes.
